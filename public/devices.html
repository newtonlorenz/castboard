Image mode

Castboard draws the screen on the server. The display receives an image and sends taps back. Use this for the full design and browser plugin controls.

Requires the optional image renderer. Photos and artwork must be served by Castboard.

Native mode

The display draws a lightweight view of each plugin. It uses less bandwidth and can keep the last view when Wi-Fi drops.

Plugins and layouts need a native view. Compatibility is listed for each display.

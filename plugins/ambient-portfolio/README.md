# Ambient Portfolio

Positions, prices and totals from a portfolio source.

Install from **Plugins → Library**, then configure the installed copy in admin. Use **Add to a screen** to place a panel; its options are also available in Studio.

Admin settings: Title, Refresh · seconds, Positions to show.

Panel options: Title, Refresh · seconds, Positions to show.

Required packages: ambient-runtime, ambient-theme, ambient-config-source, ambient-services, ambient-portfolio-source. Admin connects these automatically when installing.

See [Ambient setup and contracts](../../docs/AMBIENT-PLUGINS.md). For package metadata, lifecycle and privacy, see [plugin authoring](../../docs/PLUGINS.md).

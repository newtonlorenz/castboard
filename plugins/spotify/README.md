# Spotify

Playback through spotify_player or read-only JSON.

Install from **Plugins → Library**, then configure the installed copy in admin. Use **Add to a screen** to place a panel; its options are also available in Studio.

Admin settings: Data provider, Default title, Response cache · milliseconds, Request timeout · milliseconds, JSON endpoint, JSON file path, Request headers, Spotify player executable, Spotify configuration directory, Spotify cache directory, Default speaker name, Show playback controls.

Panel options: Title, Show playback controls.

See [provider payloads](../../docs/PLUGIN-CONTRACTS.md). For package metadata, lifecycle and privacy, see [plugin authoring](../../docs/PLUGINS.md).

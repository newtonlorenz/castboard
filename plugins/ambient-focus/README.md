# Ambient Focus

Current and next calendar events in a compact display strip.

Install from **Plugins → Library**, then configure the installed copy in admin. Use **Add to a screen** to place a panel; its options are also available in Studio.

Admin settings: Title, Refresh · seconds, Message with no active event, Message with no upcoming events.

Panel options: Title, Refresh · seconds, Message with no active event, Message with no upcoming events.

Required packages: ambient-runtime, ambient-theme, ambient-config-source, ambient-services, ambient-calendar-source, ambient-recovery-source. Admin connects these automatically when installing.

See [Ambient setup and contracts](../../docs/AMBIENT-PLUGINS.md). For package metadata, lifecycle and privacy, see [plugin authoring](../../docs/PLUGINS.md).

# Focus

Current and next event alongside a recovery score.

Install from **Plugins → Library**, then configure the installed copy in admin. Use **Add to a screen** to place a panel; its options are also available in Studio.

Admin settings: Default title, Message when the calendar is clear, Show recovery score.

Panel options: Title, Message when the calendar is clear, Show recovery score.

Required packages: calendar, recovery. Admin connects these automatically when installing.

See [provider payloads](../../docs/PLUGIN-CONTRACTS.md). For package metadata, lifecycle and privacy, see [plugin authoring](../../docs/PLUGINS.md).

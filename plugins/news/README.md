# News and briefings

RSS, Atom, Markdown and JSON stories with an interactive reader.

Install from **Plugins → Library**, then configure the installed copy in admin. Use **Add to a screen** to place a panel; its options are also available in Studio.

Admin settings: Data provider, Default title, Response cache · milliseconds, Request timeout · milliseconds, JSON endpoint, Markdown directory or JSON file, Request headers, RSS / Atom feeds, Markdown files to read, Maximum stories, Feed refresh · minutes.

Panel options: Title, Presentation, Stories to show, Seconds per story.

See [provider payloads](../../docs/PLUGIN-CONTRACTS.md). For package metadata, lifecycle and privacy, see [plugin authoring](../../docs/PLUGINS.md).

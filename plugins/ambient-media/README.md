# Ambient Media

Playback, speaker selection, volume, playlists and radio controls.

Install from **Plugins → Library**, then configure the installed copy in admin. Use **Add to a screen** to place a panel; its options are also available in Studio.

Admin settings: Title, Refresh · seconds, Show playback controls.

Panel options: Title, Refresh · seconds, Show playback controls.

Required packages: ambient-runtime, ambient-theme, ambient-config-source, ambient-services, ambient-media-source, ambient-resources, ambient-launch-source. Admin connects these automatically when installing.

See [Ambient setup and contracts](../../docs/AMBIENT-PLUGINS.md). For package metadata, lifecycle and privacy, see [plugin authoring](../../docs/PLUGINS.md).

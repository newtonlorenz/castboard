# Display link launcher

Opens HTTP links on a configured Cast display.

Install from **Plugins → Library**, then configure the installed copy in admin. This is a source or support package; connect it through a display plugin’s source settings.

Admin settings: Cast display name, Cast executable.

See [Ambient setup and contracts](../../docs/AMBIENT-PLUGINS.md). For package metadata, lifecycle and privacy, see [plugin authoring](../../docs/PLUGINS.md).

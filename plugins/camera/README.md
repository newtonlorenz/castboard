# Camera

HTTP images and browser-compatible camera streams.

Install from **Plugins → Library**, then configure the installed copy in admin. Use **Add to a screen** to place a panel; its options are also available in Studio.

Admin settings: Data provider, Default title, Response cache · milliseconds, Request timeout · milliseconds, Camera service URL, Camera stream URL, Camera label, Camera list path, Stream path template, Preferred camera ID, Request headers.

Panel options: Title, Camera label.

See [provider payloads](../../docs/PLUGIN-CONTRACTS.md). For package metadata, lifecycle and privacy, see [plugin authoring](../../docs/PLUGINS.md).
